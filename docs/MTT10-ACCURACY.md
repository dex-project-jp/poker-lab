# v1.3 精度検証

9人・全員強制ベット前10BB・SB0.5BB・BB1BB・BBアンティ1BB。
Chip EV・ICMなし・レーキなし。v1.2のFold / All-in / Callモデルを維持。
**完全なGTOも、厳密なExploitabilityも未確認。新しい推奨レンジは公開しない。**

## 再現

```sh
npm test --prefix solver
npm run validate:mccfr-accuracy --prefix solver
npm run check:mccfr-accuracy --prefix solver
```

1万・10万・100万反復を事前固定し、平均戦略そのものをgzip checkpointで保存。
各checkpointの平均戦略を固定し、別seedの1万配札で各席の応答候補を学習し、さらに別seedの1万配札で評価する。
学習・3応答探索・3評価の全7seedを重複禁止。最終評価でcheckpointを選び直さない。
源コードと比較資料のSHA256、実行時間、最大RSS、Node版を記録する。
チェックコマンドは保存した全平均戦略、正規化、クラス観測数、方策変化、seed分離を確認し、全応答探索・評価を再計算する。同一実装の再実行であり独立実装による認証ではない。

## 数値の意味

- 戦略変化：全510履歴×169クラスの非欠損行におけるaggressive probabilityの平均絶対差・最大差。各行を等しく重み付けする。到達確率による重み付けではない。
- Regret：各席の学習標本上の正の累積counterfactual regret / 反復数。真のBest Response上限ではない。
- EV：固定した平均戦略の別配札上での席別期待損益、単位BB / dealt hand。各EVのHoeffding区間は利得範囲[-10,80]BBを使用。
- 改善可能EV：169クラスごとに学習した固定逸脱方策と基準方策との差。同一評価配札でのpaired gain、標準誤差、区間を表示。各プレイヤーは一度のみ行動するため、この制限ゲームでは履歴ごとの最善アクションの標本学習が可能。
- 近似BRの改善幅の正部分を足した診断値は、有限標本のノイズを含む。厳密なNashConvではなく、信頼下限でもない。9人の一般和ゲームで2人零和のExploitability=NashConv/2は使用しない。厳密値・上限はnull。
- 各checkpoint内9席同時95% Hoeffding区間（理想的なIID一様抽選を仮定）。EVと改善幅両者全体、全checkpoint全体の同時95%保証は主張しない。PRNGの別seedは独立性の証明ではない。
- 未観測クラスはnullのまま保存。評価内だけ明示的に50/50を使用し、推奨値へ流用しない。

## 判定

| 表示 | 必要条件 |
|---|---|
| 未検証 | 比較前・評価なし・未観測クラスあり |
| 改善中 | 比較と評価あり、候補の基準は未達（単調改善を意味しない） |
| 収束候補 | 3checkpointあり、欠損なし、最終平均変化≤0.01・最大≤0.05、全席Regret≤0.01BB、全席の固定逸脱改善幅の区間上限≤0.01BB |
| 検証済み | 上記に加え、独立実装照合・対象範囲に対する認証済みBR上限が必要。現在の評価器からは到達不可 |

閾値は実用上の保守的な診断基準。1ポイントの平均変化・5ポイントの最大変化と0.01BBの許容値に数学的Nash保証はない。多人数MCCFR自体にも一般的Nash収束保証はない。収束候補でもGTOと表示しない。

## 公開資料との比較

出典：[HoldemResources公式HU Push/Fold表](https://www.holdemresources.net/hune)（2026-11-05確認）。
No Ante PusherのAA、72o、T2s、32sの公表しきい値のみを使用し、10BBでのJam/Foldを9人卓SB未オープン行と参考比較する。169ハンドの一致検証ではない。
HU・アンティなしと9人卓・BBA1BBでは人数、強制ベット、先行Foldによるカード除外が異なる。この差を誤差や精度保証として扱わない。境界の混合頻度や未取得データを推測で補完しない。
`MCCFR_REFERENCE=/path/to/reference.json`で追加比較も可能。必要形式は `solver/data/mccfr-reference.json` を参照。手入力資料は独立認証されない。

## 残る限界

通常Raise・Limp・3bet・4bet・ポストフロップベット・ICM・レーキは対象外。
1326コンボ自由方策に対する上限、条件一致の公開レンジ比較、v1.3の独立数値実装照合、厳密なfull-deck BR上限は未達。
v1.2のカード除外、全終端のマルチウェイ精算照合、seed再現性テストは維持。
既存の30BBレンジとPWAの更新処理は変更しない（リリース番号と読込キャッシュ識別子のみ更新）。

## 保存済み実行結果

Node v24.22.1、学習seed130101。合計約218.9秒、最大RSS約184.7MiB（機器依存）。

| 反復 | 前checkpointからの平均変化 | 最大変化 | 各席Regretの最大値 BB |
|---|---:|---:|---:|
| 10,000 | 比較前 | 比較前 | 4.3911 |
| 100,000 | 24.29ポイント | 90.80ポイント | 1.9971 |
| 1,000,000 | 21.67ポイント | 90.14ポイント | 0.4894 |

判定は **改善中**。各checkpointで9席の固定逸脱改善幅のHoeffding半幅は約3.088BBと大きい。
100万回時の近似応答候補はholdout上で全席マイナスであり、真の最適応答を十分近似できた証拠がない。低い改善幅を収束の根拠にしない。
詳細な全席EV・標準誤差・参考区間は `solver/data/mccfr-accuracy.json` とアプリ内v1.3検証画面を参照。

`npm test --prefix solver` は118件成功。既存のPython独立照合（BTN小規模ゲーム、9人制限ゲーム、実デッキ配札・精算、v1.2 MCCFR）も成功。
ローカルのPlaywright画面テストはブラウザー実行ファイルを取得できず実行不可。画面の描画・不正データの非表示処理はNode上でテストし、実ブラウザー確認はGitHub Actionsに残す。
