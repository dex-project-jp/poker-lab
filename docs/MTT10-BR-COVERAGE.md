# 10BB近似BR：到達重み・有効標本数の診断

## 対象

9人、全員10BB（強制ベット前）、SB0.5/BB1/BBA1BB、Chip EV、ICM・レーキなし。Fold/All-in/Call限定。各プレイヤーは一度だけ行動するため、行動前の自分のreachは1であり、先行プレイヤーの行動確率の積がcounterfactual reachになる。

既存の `fitResponseFast` は、各配札で手札クラスを観測すると、そのプレイヤーの全履歴でクラス観測数を増やす。しかし候補行動の価値集計は到達重みを掛けるため、観測回数が多くても有効情報が少ない履歴がある。この工程では元の探索/学習コードに手を入れず、分離した診断でその差を測る。

## 再現

```sh
npm run diagnose:mtt10-br --prefix solver
npm run check:mtt10-br --prefix solver
# 全510履歴×169クラスから任意行を調査（0始まり）
npm run check:mtt10-br --prefix solver -- --row=509:0
```

履歴は `TREE.infos[infoIndex]`、手札は `CLASSES[handClassIndex]` に対応。API `createCoverageAudit().row(info, hand)` は各行のクラス観測数、非ゼロ重み数、重み合計・二乗和・ESS・状態を返す。集計レポートは位置別件数と不足例を保存し、任意行は固定seedで再生成する。レポートの `sources` が源コードと入力データのSHA256を固定し、checkコマンドは両seedを再計算して保存内容と完全一致を確認する。

入力はv1.3保存済み100万反復・学習seed130101の**全行が定義済みの研究方策**。公開v1.5の参考レンジとは異なる。公開データの非表示379行を埋めていない。新規診断seed160201/160202で各10,000配札を事前に固定し、再学習はしない。

## 数式と状態

手札クラスを観測した配札の重みを `w` とし、`ESS = (Σw)² / Σ(w²)` を計算。等しい正の重みならESSは非ゼロ数と一致し、一部の重みに集中すれば減る。スケールした和で計算し、非常に小さい正の重みの二乗が浮動小数点で0になる場合もESSを維持する。二乗和のunderflowフラグと対数値を返す。reachの積自体が0へunderflowした場合は、真の到達不能と区別できない。

| 状態 | 意味 |
|---|---|
| no-class-samples | 当該手札クラスを未観測、ESS未算出 |
| zero-reach | クラスは観測したが非ゼロ到達重みなし、ESS未算出 |
| low-ess | 正の重みがありESSが30未満 |
| diagnostic-only | ESSが30以上。検証済みの意味ではない |

30は不足箇所の優先調査に使う便宜的な目安。正規近似・誤差保証・戦略認定に使わない。ESSが高くても重みの絶対量や行動EVの分散、観測していない稀な配札を保証しない。ESSだけで戦略の優劣を判定しない。

## 結果

全86,190行でクラス観測あり、非ゼロ重みありだった。一方で以下の不足を確認した。

| 診断seed | ESS 30未満 | ESS 30以上（診断のみ） |
|---|---:|---:|
| 160201 | 85,689（99.42%） | 501 |
| 160202 | 85,696（99.43%） | 494 |

詳しい位置別内訳と具体例は `solver/data/mtt10-br-coverage.json`。履歴が多い後方ポジションの行数が多いため、全行割合を実戦での遭遇確率と混同しない。

この結果は「各1万配札でこの固定研究方策を調べた診断」であり、v1.3の過去の全BR探索やv1.5公開レンジを直接評価したものではない。独立seedの再現で母集団全体の不足率を厳密推定したとも主張しない。

## 検査と限界

等重み・偏重み・0・1e-200の手計算、独立した木の再帰による全履歴の到達確率、到達不能履歴の観測回数、入力欠損拒否、入力不変性、固定seed再現をテストする。従来のカード除外・精算・サイドポット・学習・UIテストも維持。

応答を新たにfitしておらず、EV改善・Exploitability低下・収束改善は未確認。厳密BRや真のExploitability上限は算出していない。認定閾値・公開戦略・アプリ表示は変更せず、GTO未認定を維持。通常Raise/Limp、ポストフロップ、ICM、レーキは評価対象外。

次工程は、診断に基づく低到達履歴の応答探索方法を小さな独立ゲームで検証し、採用前にfit/選択/holdoutを分離して誤差込みの改善比較を行うこと。100万反復の再学習や対応ゲームの拡大を先に行わない。
