# iPhone向け段階選択 UI v0.9

## 操作

初期状態は30BB・9人卓・BTN・全員フォールドの参考表です。
最初に開くのは「① 状況」だけ。ポジションとサイズは短い見出しにまとめます。

1. 状況を選ぶと「② 役割・位置」が開く。
2. 自分と相手の位置を選び「次へ：サイズ」を押す。
3. Open・3bet・4betの必要な欄だけを編集する。
4. 「レンジを見る」で編集欄を閉じる。

各段階の見出しをタップすれば、その項目を再編集できます。
一度に開く段階は一つだけです。ハンドの推奨は従来どおり固定表示します。
モード・スタック・アンティは上部の「設定」で開くシートへ移しました。
根拠・適用条件・詳しいチップ計算・更新操作も折りたたみました。
新しい版が見つかった場合は更新欄を開いて通知します。勝手な再読み込みはしません。

## 行動順

- 対Openの自分はUTGより後。オープナーは自分より前。
- 対3betの自分はオープナー。BBはオープナーにしない。
- 対4betの自分は3-bettor。UTGはその役割にしない。
- コールド4betはOpen → 3bet → 自分の順で位置を指定できるが参考レンジは未対応。

場面を変更して以前の位置が使えなくなった場合、合法な初期位置に切り替え、
選択済み見出しに現在の位置を示します。不可能な位置ボタンは無効にします。
HUと小規模検証モデルの役割・固定アクションは既存仕様を維持しています。

## 自由入力と計算

Openは2/2.2/2.5/3BB、3betは6/7/8/9/10/12BBとAll-in、4betは12/14/16/20BB等を
プリセットから選べます。全サイズは0.01BB単位で自由入力できます。
標準プリセットでは、Openの位置とIP/ブラインドの役割に合わせて従来サイズを設定します。
非標準プリセットや自由入力は、位置を変えても勝手に標準へ戻しません。
標準を再選択したときや、学習モード・MTTスタックを切り替えたときは基本値へ戻ります。

入力はすべて「ライブベットの合計BB」です。追加BBではありません。
アンティはデッドマネーとして別に引き、本人のライブ上限を求めます。
`app/preflop-bets.js` は0.01BB単位の整数で次を計算します。

- 現在のポットと本人の残りチップ
- Callの追加額、Call後ポット・残り、未コール分返却
- 前回フルレイズの増分から求めた最小フルレイズ合計
- 指定した次のRaiseを行う場合のポット・残り
- All-in上限、短いAll-inによる再レイズ不可、上限未満ではフルレイズできない状態

Open場面の現在ポットは、まだ指定Openを出す前の強制ベットの合計です。
指定Raise後のポット・残りを別項目として表示します。SBでLimpを推奨するハンドにも、
指定Openの予測値をLimpの実行結果として説明しません。

例：BTN2.2BB → BB7.5BB → BTN16BBなら現在ポット25BB、BBの追加Call8.5BB、
Call後33.5BB、最小フルレイズ合計24.5BB。BBアンティ1BBならBBのライブ上限は29BBです。

過小レイズ、上限超過、空欄、非数値、過剰な桁数にはエラーを表示します。
過小でも本人の全チップを出す短いAll-inは合法として扱い、再レイズできるかを分けます。
相手がAll-inで続行者が2人だけならCall/Foldに限ります。
ポット計算は、他の7人がFoldした2人続行局面を対象とします。
強制ベットだけでAll-inするスタックや、マルチウェイ・サイドポットはこの計算では未対応。

## 参考レンジの対応判定

金額が合法でも戦略が検証済みになるわけではありません。
従来の9人・全員30BB・BBA1BB等に加えて、局面に関係するサイズと自分のRaise候補が
従来のOpen2/SB2.5・3bet6/7/8・4bet14/All-inと一致する場合だけ既存表を表示します。

範囲外では「このサイズの推奨レンジは未検証」と表示し、セルの推奨色・アクションを消します。
Foldや0%で埋めず、標準サイズへ戻すと再び表示します。
同じ理由で、条件付きAll-in比較も現在の対応履歴に限定し、別サイズへ自動流用しません。
数値計算だけを行う機能と、戦略データの利用条件を分離しています。

## 検証範囲と限界

既存108リレイズ履歴と新しい金額台帳を照合し、自由サイズ、0.01BB計算、
アンティ別計算、短いAll-in、上限返却、最小レイズ・不正入力を検査します。
スマホ幅375/390/430pxのChromium・WebKitで、段階表示、見出しからの再編集、設定シート、
標準への復帰、サイズ範囲外の色消去、HU・混合描画・All-in条件比較・更新復元を確認します。
WebKitもiPhone実機そのものではありません。ホーム画面独立アプリの実機検証は別途必要です。
ページ再読み込みで学習条件を永続復元する機能は今回追加していません。

## v0.9.1 スマホ表示の改善

- 自分のポジションを最上段に常設し、役割選択の中から重複する位置選択を削除。
- ①全員フォールドが初期値。②は別の状況を選ぶまで非表示、③は「次へ：サイズ」または任意のOpenサイズ変更を押すまで非表示。
- 状況変更時は③を再度隠し、不要な選択欄を残さない。見出しから再編集する既存操作は維持。
- 更新操作を折りたたみ内部だけに置かず、ヘッダーの「↻ 更新」から直接実行可能にする。既存の更新確認と通信失敗時の保護は維持。
