# 30BB実戦参考レンジ v1

## データの種類・利用範囲

これは**Poker Lab独自の戦略設計による、保守的な基本表**です。
ソルバー計算による近似均衡、他社が公開したレンジの転載、検証済みGTOではありません。
相手が誤るからこの表のEVが保証される、という意味でもありません。

今回のハンド境界と説明文は新規に作成し、他社の有料・無料レンジ表、画像、
169ハンドの頻度データは取り込んでいません。一般原則の参考資料を下記に示します。
公開ページを閲覧できることを、データの商用再配布許可とは扱っていません。
既存の第三者コード nuts のMITライセンスは同梱を維持しています。

## 前提

| 条件 | 定義 |
|---|---|
| 卓・スタック | NLHE、9人卓MTT、全員30BB、ブラインド・アンティ支払い前 |
| ポジション | UTG → UTG+1 → MP（内部ID UTG+2）→ LJ → HJ → CO → BTN → SB → BB |
| 強制ベット | SB0.5BB、BB1BB、BBアンティ1BB。開始ポット2.5BB |
| 通常オープン | UTG〜BTNは合計2BB、SBは合計2.5BB |
| SBのLimp | 合計1BBへコンプリート（追加0.5BB）。レイズ後の自動コールではない |
| Open All-in | アクション形式は扱うが、今回の30BB基本表では採用しない。最適な頻度0%との主張ではない |
| 評価方針 | Chip EV志向、レーキ0、ICM・バウンティなし。EV自体は未計算 |
| 対オープン | オープナー1人のみ、間の全員はFold、追加のコーラーなし |
| 3betサイズ | IPは合計6BB、SB/BBは合計7BB、BB対SB2.5BBオープンは合計8BB |
| 未対応 | 他スタック、別アンティ・サイズ、コールドコール複数人、スクイーズ、3bet/4betへの応答、ICM |

表示は各ハンドに一つの**基本推奨**を割り当てます。
Raiseを推奨したセルは「GTOで100%レイズ」とは意味しません。
パーセンテージのアクションバーは参考表では使いません。
採用コンボ数とその比率は、下記ルールを6/4/12コンボで数えた結果のみです。

## 独自のオープン設計

- 早い位置では、後ろに残る人数、強いレンジとの衝突、オフスートのキッカー負けを重く見る。
- 後ろの位置へ移るごとに、ペア、スート、連結性、ブロッカー、高いカードを順に加える。
- 下の表は今回の手動設計の境界であって、EV=0の境界を計算したものではない。
- UTG〜BTNはRaise/Foldに簡略化し、オープンリンプやジャムを採用しない。
- SBは価値レイズと一部のスート・ブロッカー枠をRaiseにし、残りの参加可能手をLimpにする。
  **強い手をRaiseに寄せた簡略化なので、Limpレンジのバランス保証はない。**
  BBが頻繁にアイソレイズするなら参加範囲・強い手のLimp等の再設計が必要。

記法：55+ は55〜AA、A5s+ はA5s〜AKs。`追加`は前の位置の全Raiseを引き継ぐ意味です。

| 位置 | Raiseに使う独自ルール |
|---|---|
| UTG | 55+ A5s+ KTs+ QTs+ JTs T9s 98s AJo+ KQo |
| UTG+1 | 追加：44 A4s A3s Q9s J9s T8s ATo |
| MP | 追加：33 A2s K9s 87s 97s KJo QJo |
| LJ | 追加：22 K8s Q8s J8s 76s 86s A9o KTo |
| HJ | 追加：K7s Q7s T7s 65s 75s A8o QTo JTo |
| CO | 追加：K6s K5s Q6s J7s T6s 96s 54s A7o K9o Q9o |
| BTN | 追加：K4s K3s K2s Q5s Q4s J6s J5s T5s 95s 85s 64s A6o A5o A4o K8o K7o Q8o J9o J8o T9o 98o |
| SB | 55+ A8s+ ATo+ KTs+ KJo+ QTs+ QJo JTs T9s A5s A4s K5s Q5s |

SBの参加集合：全ペア、全suited、全Ax/Kx offsuit、Q6o+、J7o+、T7o+、
98o 87o 76o 65o 54o 97o 86o 75o 64o。Raiseに指定された手を除きLimp、それ以外はFold。

オープンの採用コンボ数はUTG176、UTG+1 214、MP260、LJ310、HJ366、CO430、BTN594。
SBはRaise212・Limp718・Fold396。これらは強さの検証値ではなく、定義からの正確な集計です。

## 単独オープンへの応答

UTG/UTG+1/MPを早い位置、LJ/HJを中間、CO/BTN/SBを後ろの位置として分類。
単独オープンの相手位置と自分の位置で、元のハンド集合から3betとCallを選別します。

- 早い位置のオープンには強いペア・AKを中心に3bet。IPのCallは中ペアと強いsuited中心。
- 中間・後ろの位置には価値3betの枠を広げ、A5s/A4sをブロッカー重視の3bet候補に採用。
  これらを毎回3betするのがGTO、あるいは最適なブラフ率という意味ではない。
- SBの対オープンは、OOPかつBBの再参加リスクを抑える簡略化として3bet/Fold。
- BBは、すでに支払ったブラインドと良い参加価格を考慮してCallを広げる。
- 同じ手が3bet集合とCall集合の両方に入る場合は3betを優先。残りはFold。
- 全36の合法な「先にオープンした位置→後ろで応答する位置」で169手を定義する。
  UTG対BTNオープンのような行動順違反は非対応。

全ルールは[practical-ranges.js](../solver/practical-ranges.js)に明記し、
[機械可読の集計](../solver/data/practical30-summary.json)にも残します。
4bet・オールインへのコール可否はこの表から推論しません。

### 計算した数値と、計算していない数値

計算したもの：ハンド展開、169クラスの網羅、ペア6／suited4／offsuit12の1,326コンボ集計、
ライブベットの追加額、単純なポットオッズ。
例：BBがBTNの2BBオープンにCallする追加額は1BB。現在ポット4.5BBに対する
単純閾値は1/(4.5+1)=18.18%。BBアンティをCall代として二重に数えません。
これは後続アクション・エクイティ実現率を無視した計算で、Callの利益を証明しません。

未計算：各ハンドのEV、アクションの最適混合頻度、Nash gap、攻略可能性、相手プールへの勝率。
テスト通過はルールの実装・整合性の確認であり、ポーカー戦略の最適性の証明ではありません。

## 一般原則の参考資料（表・数値は転載しない）

- [PokerStars Learn：Position](https://www.pokerstars.com/poker/learn/lesson/position/)
  前の位置は絞り、後ろは広げること、後ろの位置の情報優位を参考にしました。
- [GTO Wizard：Is Limping Pimping?](https://blog.gtowizard.com/is-limping-pimping/)
  SBにLimpを持つ設計があるという概念のみを参照。解や混合頻度は取り込んでいません。
- [PokerStrategy：Open Raising](https://www.pokerstrategy.com/strategy/sit-and-go/playing-preflop-open-raising/)
  スタック・位置とレイズサイズを合わせ、深いところで小さく開く一般原則のみを参考にしました。
