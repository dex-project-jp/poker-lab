# 条件付き抽選による近似BR探索の検証（有限ゲーム）

## 結果と採用判断

**本番エンジンには採用しない。** 条件付き抽選の重み補正と有限ゲーム内の分散低下は確認できたが、9人・52枚のMTTに対する精度/速度改善は未検証。固定逸脱候補の独立holdoutも、事前に定めた保守的区間ではEV改善を確認できなかった。既存のGTO認定基準・公開戦略・UIは変更していない。

前工程のESS診断を受け、列挙可能な小さなゲームで候補方式の数学的な正当性を確認した。実戦データや外部レンジによる補完ではない。

## 実験の範囲

- BTN/SB/BBの3人、強制ベット前10BB、SB0.5/BB1/BBA1BB、Chip EV、ICM/レーキなし。Fold/All-in/Callのみ。
- AA/KK/QQ/JJから異なるペアランクを重複なしで3人へ配る24等確率世界。各ペアの全6スート組合せを含む5,184物理配札と等価。
- 既知ボード2c 3d 4h 8c 9d。スートによらずペアの強さ順で決着。全スートの評価とカード除外をテスト。
- 先行6席とそのカード、全52枚の未知配札/未知ボード、通常Raise/Limp、ポストフロップは対象外。9人卓10BBの代用レンジではない。
- 6履歴×4ハンド＝24行。固定した人工方策を両方式で共用し、学習しない。方策確率は1/10,000格子に限定し、未対応の精度の方策は拒否する。

## 推定量

世界を `d`、その確率を `p(d)=1/24`、対象行の手札条件を `H`、先行行動の到達確率を `r(d)`、行動価値差を `Δ(d)` とする。

目的の非正規化行動価値差は `A = Σ p(d) 1_H r(d) Δ(d)`。

従来方式は全配札を一様抽選し、該当する手札行へ `rΔ` を集計する。候補方式は `Z = Σ p(d) 1_H r(d)` を列挙し、`q(d) = p(d) 1_H r(d) / Z` から抽選する。補正した `Z × 平均(Δ)` の期待値はAと一致する。条件付き平均を非条件付きEVへ転用しない。

このゲームでは各人が一度しか行動せず、自分の先行reachは1。相手の固定方策の積で対象履歴のcounterfactual reachを求められる。Zが0の行は抽選せず、固定方策を保持する。

抽選には整数のチケット数と32bit整数の棄却法を使う。経路長が最大2、方策が1/10,000格子なので、各世界の到達確率を最大1億分の整数で表現できる。浮動小数点CDFの丸めや剰余バイアスを抽選確率へ持ち込まない。PRNGは既存のMulberry32で再現可能だが、真の独立乱数の証明ではない。

通常のimportance samplingの定義は [Art Owen, Monte Carlo theory, methods and examples, Chapter 9](https://artowen.su.domains/mc/Ch-var-is.pdf) を参照。このゲーム用の期待値・分散は上式から直接計算し、独立した有理数実装で照合する。一般にESSや重みの均等化だけで行動EVの誤差改善を保証しない。

## 固定した比較計画

fit seed 170201/170202/170203、配札予算N=64/256/1024。探索前の単一seed試行170101は確認結果から除外。従来はN配札で各履歴を評価し、候補は各行N/4回。両方の行動価値参照回数は `N×6`。

候補の提案分布は既知の24世界を列挙して作る。その前処理、全表の作成、厳密oracleの計算は上の参照回数に含まない。時間・終端評価回数を揃えた速度比較ではない。全世界を列挙できる本ゲームでは、そのまま厳密BRも計算できる。あくまで抽選と補正を検査する実験であり、52枚ゲームで同じ列挙が実用的だという根拠にはならない。

候補選択はfitとは別seed（+1000）の8,192配札で、位置別改善のHoeffding下限が正のときのみ採用。最終評価はさらに別seed（+2000）の8,192配札で、選択に使わない。両方式を同じ評価配札で比較する。予算間では同じseedを再使用するため、9実験を9独立反復と数えない。

選択18評価、および最終のraw/選択後18評価それぞれで、各評価のalphaを0.05/18に配分。各区間は3席同時の両側Hoeffding区間。各人の効用範囲[-10,20]BBから、固定した2応答の差の範囲[-30,30]BB（幅60）を使う。保証は理想IID仮定下であり、GTO/Exploitabilityの上限ではない。標準誤差も併記するが、それを使って認定閾値を緩めない。

## 観測した数値

独立Pythonの有理数oracleと、ポット分配・到達重み・行動価値差・厳密BR・推定量の分散・全応答の成績が一致した。厳密BRとは**この有限ゲームの固定方策に対する応答**だけを意味する。固定方策自体をGTO認定していない。

| N | seed | 従来の行動誤り数 / 24行 | 条件付きの行動誤り数 |
|---:|---:|---:|---:|
| 64 | 170201 | 0 | 0 |
| 64 | 170202 | 2 | 0 |
| 64 | 170203 | 0 | 0 |
| 256 / 1024 | 各3seed | 全て0 | 全て0 |

N=64・seed170202の厳密BRに対するEV損失は、従来がBTN 0.974001BB / SB 0.314303BB / BB 0BB、条件付きが全席0BB。他の条件は両方式とも0BB。この固定方策の全24行で候補の理論的推定分散は従来より小さいが、他の方策/ゲームにも成立するという主張はしない。

同ケースの独立raw holdout（候補−従来）は以下。区間は全て0を含む。

| 席 | 平均差 BB | 標準誤差 BB | 保守的区間 BB |
|---|---:|---:|---:|
| BTN | +0.982655 | 0.031294 | [-0.316202, 2.281513] |
| SB | +0.316059 | 0.020652 | [-0.982798, 1.614916] |
| BB | 0 | 0 | [-1.298857, 1.298857] |

候補選択は両方式・全条件・全席で固定方策を保持した。選択後の差は全て0だが、これは均衡の証拠ではない。有限oracleによる局所的な改善と、採用判定に使う独立評価の未達を分ける。
